Welcome to Glue Stick

About Glue Stick

Glue Stick is a specialized Discord bot designed to keep your important messages visible and accessible. Whether it's server rules, announcements, or key information, Glue Stick ensures your message stays at the bottom of the channel where everyone can see it.

Perfect for: Server rules, announcements, important links, channel guidelines, and any message that needs to stay visible!

Key Features

  • Persistent Messages: Keep any message "glued" to the bottom of a channel. The bot automatically maintains its position as the most recent message.
  • Modern Slash Commands: Easy-to-use slash commands with no prefixes to remember - just type / and see the options.
  • One Message Per Channel: Each channel can have one glued message, which can be easily updated or replaced.
  • Automatic Management: The bot handles everything automatically - no manual intervention needed.
  • Server-Wide Control: Administrators can manage all glued messages across the entire server.

Getting Started

  1. Invite Glue Stick: Add to Your Server
  2. Grant Permissions: Make sure the bot has permission to send messages and manage messages in your desired channels.
  3. Use the Commands:
    • /glue [message] - Create or update a glued message in the current channel
    • /unglue - Remove the glued message from the current channel
    • /clearallglues - Remove all glued messages from the entire server
