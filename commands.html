Bot Commands

Available Commands

  • /glue

    Glue a message to a channel.

  • /gluepara

    Glue a multi-line message to a channel.

  • /glueembed

    Glue an embed message to a channel.

  • /unglue

    Removes a glued message from a channel.

  • /editglue

    Edit the currently glued message in this channel.

  • /listglues

    List all glued messages in the server.

  • /clearallglues

    Clear all glued messages in the server.

  • /help

    Get information about Glue Stick commands and features.

  • /ping

    Replies with Pong! Shows bot latency and shard information.

  • /permcheck

    Check Glue-Stick's permissions in the current channel.

  • /invite

    Get an invite link for Glue Stick bot.

  • /support

    Get an invite link to the Glue Stick support server.

  • /vote

    Get the link to vote for the bot on top.gg.
